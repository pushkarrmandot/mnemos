## Decisions the next waves must not re-litigate

1. **`data-theme`, not `.dark`.** Per SHELL_CHEATSHEET §3, which supersedes
   DESIGN_SYSTEM §9 and FRONTEND_STANDARDS §5 on this point. The Tailwind
   `dark` variant is defined against the attribute in `global.css`.
2. **Theme lives in `useUIStore`.** W3 extends this store; it does not create a
   second one. `localStorage["mnemos.theme"]` holds the bare preference string
   (not zustand's JSON envelope) so `public/theme-init.js` can read it with one
   `getItem`.
3. **`bg-*` / `text-*` / `border-*` token utilities are hand-declared** in a
   trailing `@layer utilities` block, not `@theme` colors. Tailwind's color
   namespace can't hold `bg-subtle` (a surface) and `border-subtle` (a line)
   under one key, and `text-primary` (our body text) collides with the
   `primary` key shadcn needs for `bg-primary`. Adding a new surface token
   means adding a rule to that block.
4. **File-based routing with an `_app` / `_bare` layout split.**
   `src/routeTree.gen.ts` is generated by the Vite plugin, committed, excluded
   from Biome, and guarded in CI by a build-then-`git diff` step.

## Needs owner sign-off

1. **`exactOptionalPropertyTypes` is now off** (`tsconfig.app.json`). Vendored
   shadcn does not compile under it — `DropdownMenuCheckboxItem` spreads
   `checked?: CheckedState` into a required prop — and FRONTEND_STANDARDS §4
   forbids editing `components/ui/*`. The alternatives were forking vendored
   code or permanently restricting which shadcn components the project can use.
2. **The no-FOUC script is a file, not inline.** `tauri.conf.json` pins
   `script-src 'self'`; an inline script would be dropped by CSP in the
   packaged app. Same behaviour, different location: `public/theme-init.js`.
3. **Framer Motion is not installed yet.** Everything W2 needed was expressible
   as CSS transitions off the `motion-*` utilities. `src/design/motion.ts`
   already exports the §14 curves in Framer's value format, so W6/W9 can add
   the dependency without re-deriving anything.

## Landmines

- `components/ui/*` is vendored and Biome-excluded. Never edit it; re-add with
  `pnpm dlx shadcn@latest add <name>`, which writes into a literal `@/`
  directory in this repo — move the files into `src/components/ui/` afterwards.
- `pnpm biome ci` needs `css.parser.tailwindDirectives` (already set) or it
  fails to parse `@utility` / `@custom-variant`.
- Adding or renaming a route file changes `src/routeTree.gen.ts`. Run
  `pnpm vite build` and commit it, or CI's drift check fails.
