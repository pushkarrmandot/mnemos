# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in Mnemos, please
report it privately rather than opening a public issue — public issues are
visible to everyone before a fix is available.

Email **pushkarmandot@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal repro is very helpful)
- Any relevant logs, screenshots, or proof-of-concept code

## What to expect

Mnemos is currently a solo-maintainer project, so response times are
**best effort** rather than guaranteed. You'll get an acknowledgment as
soon as possible, and updates as the issue is investigated and fixed.

Please do not disclose the vulnerability publicly until it's been addressed.
