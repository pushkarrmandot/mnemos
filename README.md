# Mnemos

Local-first meeting memory. Tauri v2 host (Rust) + React 19 frontend, with a
Python worker and Swift audio sidecar arriving in later waves.

**Status: Wave 1 — boilerplate.** The window opens and one `ping()` command
round-trips through `tauri-specta`-generated bindings. No features yet.

## Prerequisites

- Node 22 + pnpm 10 (`corepack enable`)
- Rust stable (`rustup`), MSRV 1.80
- macOS: Xcode Command Line Tools

## Getting started

```sh
pnpm install
pnpm dev            # == pnpm tauri dev — builds Rust, starts Vite, opens the window
```

## Checks

```sh
pnpm lint           # biome check
pnpm typecheck      # tsc -b (project references: app + node configs)
pnpm test           # vitest
cargo fmt --check   --manifest-path src-tauri/Cargo.toml
cargo clippy        --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test          --manifest-path src-tauri/Cargo.toml
```

Install the pre-commit hooks with `pnpm dlx lefthook install`.

## Layout

```
src/                 React frontend (FRONTEND_STANDARDS §1)
  ipc/               the only module allowed to import from bindings/
src-tauri/           Rust host (BACKEND_STANDARDS §1)
  src/commands/      one file per feature area; W1 has ping only
  src/error.rs       AppError — flat, kind-tagged, the single wire error type
bindings/tauri.ts    generated by tauri-specta; committed, CI diff-guarded
```

`src-python/` (W5) and `src-swift/` (W7) land in later waves.

## Generated bindings

`bindings/tauri.ts` is regenerated on every debug boot and by
`cargo test specta_bindings`. Never hand-edit it — CI fails on a dirty diff.
Features import from `@/ipc`, never from `bindings/` directly.
